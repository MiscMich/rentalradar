# Provenance

This repository is a deliberately small public reference edition extracted from a larger private RentalRadar SaaS codebase. The private product includes production integrations and operational material that are not published here.

The scoring model, provider interface, tenant-isolation example, responsive UI, tests, and fictional fixtures in this repository are real source code. Persistence, authentication, billing, scheduling, and provider-specific production connectors are intentionally absent.

The public history starts with one root commit so private product history and customer-facing artifacts are not exposed.
